=== 我撰寫的 Dockerfile 內容 ===
FROM python:3.11-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

EXPOSE 5000

CMD ["python", "app.py"]

=== docker build 輸出 ===

執行指令：
docker build -t ship-api:v1 .

=== 觀念題 ===
Q1：Dockerfile 中 RUN 和 CMD 有什麼不同？分別在什麼時候執行？
A1：
RUN 是在建立映像檔時執行的指令，常用來安裝套件、建立目錄或設定環境，執行結果會被寫進映像檔的 layer。CMD 是容器啟動時預設要執行的指令，例如 python app.py。簡單說，RUN 發生在 docker build 階段，CMD 發生在 docker run 啟動容器階段。

Q2：為什麼要先 COPY requirements.txt 安裝套件，再 COPY . . 複製程式碼？
   如果反過來，每次改 app.py 時會多做什麼事？
A2：
這樣做可以善用 Docker 的 build cache。requirements.txt 通常不會每次都變，所以先複製並安裝套件後，只要套件清單沒有改，Docker 下次 build 就可以重用快取，不必重新安裝套件。如果先 COPY . .，每次修改 app.py 都會讓後面的 RUN pip install 重新執行，導致每次 build 都重新下載與安裝套件，浪費時間。
